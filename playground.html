Drive a Claude Code session

A scripted simulation with real state. Switch modes, install hooks, set a goal, and watch each choice change what the "agent" does next. The panel on the right shows the harness as it evolves.

ℹ️

This is not a real model. Responses are scripted for teaching. The commands and concepts mirror Claude Code; outputs are illustrative.

Mission: guardrails beat approvals

Ask Claude to “delete the build folder”. It asks; you click yes on autopilot. Now run /hooks install block-rm and ask again. That's lesson 5 in one minute.

Mission: plan, then act

Run /plan add a search bar. You get a plan and no edits. Pick acceptEdits in the panel (or cycle with shift+tab: plan → auto → default → acceptEdits), then say “implement the plan”. See lesson 3.

Mission: a finish line it can't fake

Set /goal tests pass, lint is clean and the dark mode toggle works. Watch the evaluator say “not yet met” until the evidence is in the transcript. See lesson 4.

Mission: skills & sub-agents

Ask for “release notes” without naming a skill, then “use the code-reviewer agent to review my changes”. See lessons 6 and 7.
