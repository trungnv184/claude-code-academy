Permission rules

RuleMatches
BashEvery Bash command
Bash(npm run test *)Commands starting npm run test
Bash(npm run test:*)Same — legacy :* form
Bash(ls *)ls -la but not lsof (the space matters)
Read(./.env)Reading that file
Edit|Write pathsEdit(src/**) style path globs
Orderdeny → ask → allow; first match wins
CaveatBash rules are prefix matches, not a security boundary — use hooks/sandbox

Permission modes

ModeBehavior
defaultAsks before edits and most commands
acceptEditsAuto-approves file edits + common fs commands
planRead and plan only; edits blocked until you approve
autoRuns with fewer interruptions; good for unattended goals
dontAskDenies anything not pre-allowed (locked-down CI)
bypassPermissionsNo checks — only in isolated sandboxes
--permission-mode planStart a session in a given mode
